**SlideForge AI** is an AI-powered presentation content generator that helps you turn a basic topic or idea into a structured presentation plan.

Instead of creating an actual PowerPoint file, SlideForge AI generates **what each slide should contain, slide by slide** — including titles, key points, structure, and presentation direction.

🔗 **Live Demo:** (https://slideforge-ai.netlify.app)

---

## 🚀 What Does SlideForge AI Do?

Creating a presentation from scratch can take a lot of time.

You usually have to decide:

* What should the presentation be about?
* How many slides are needed?
* What should go on each slide?
* Which points are important?
* How should the information be organized?
* What should the introduction and conclusion contain?

**SlideForge AI helps solve this planning problem with AI.**

You provide the necessary information about your presentation, and the system generates a **structured slide-by-slide content idea**.

### Example

Instead of manually planning:

```text
Slide 1 → Introduction
Slide 2 → Problem
Slide 3 → Causes
Slide 4 → Examples
Slide 5 → Solution
Slide 6 → Conclusion
```

SlideForge AI can turn your topic into a more detailed presentation structure such as:

```text
Slide 1 — Introduction
• Presentation title
• Brief overview
• Why the topic matters

Slide 2 — The Problem
• Main problem
• Key statistics or context
• Why it needs attention

Slide 3 — Causes
• Major causes
• Supporting explanation
• Real-world examples

...

Slide 8 — Conclusion
• Main takeaways
• Final message
• Suggested closing statement
```

The generated content can then be used to create the actual presentation in **PowerPoint, Google Slides, Canva, Gamma, or other presentation tools**.
